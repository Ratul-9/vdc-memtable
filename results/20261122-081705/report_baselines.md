Patterns: **seq** = keys 0..N-1 in ascending order; **dense_rand** = keys 0..N-1 in random order; **rand** = N random keys from the whole domain in random order.
Operations: **insert** = N new keys into an empty table; **get_hit** / **get_miss** = lookups of present / never-written keys; **get_batch** = get_hit through the prefetching batch API; **update** = overwrite present keys; **delete** = tombstone present keys.
