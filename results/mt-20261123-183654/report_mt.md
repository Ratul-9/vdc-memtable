Workloads: **load** = insert every key into an empty table; **A** = 50% get / 50% update; **B** = 95% get / 5% update; **C** = 100% get; **W** = 100% update;
Distributions: **uniform**; **zipf** (theta 0.99, hottest keys 0, 1, 2, ...); **interleaved** (worker w uses keys w, w+W, w+2W, ...: neighbouring keys at the same time).
Delegation designs spend part of the thread budget on consumers: their throughput is what the producers get done with the same number of cores.
